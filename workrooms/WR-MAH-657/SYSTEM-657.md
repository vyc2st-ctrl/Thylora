## 3. What "OPEN" means, and the meaning of completion

**OPEN** (old meaning) = the branch exists, but nobody owns the next step and there is no date. That is why branches sat still.
**New rule:** OPEN is retired. Every branch is in exactly one state:

`MOVING (owner + next action + date)` · `WAITING ON YOU (one-tap card in the alert queue)` · `DONE (witnessed)`

**Completion equation.** `Done = g₁ × g₂ × … × gₙ` (each gate is 0 or 1; any 0 → not done).
- **Store product:** file attached × download opens × phone view × price set
- **Movie / show:** script × cast × location × rights × cut
- **PDF / book:** content × layout × glyph check × your yes

**"Nothing stands still" rule:** a MOVING branch with no change in 24 hours triggers an alert.
