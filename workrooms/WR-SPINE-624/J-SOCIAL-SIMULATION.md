## 4 · What THYLORA does differently: people have persistent causal lives

| # | Law / principle | How the surveyed games do it | How THYLORA does it |
|---|---|---|---|
| D1 | **Continuity: nothing resets** | Save and reload, time travel, aging switched off, new game | The log is append-only. A correction is a new event pointing at the old one, never a deletion. There is no rewind, and an existing life cannot be restarted. |
| D2 | **Life Snapshot law** (`THY-LAW-LIFE-SNAPSHOT-001`) | Visuals are authored assets and live state is drawn directly | Every visual is a **projection of persistent state at a timestamp t**: snapshot = f(Log ≤ t). | D3 | **World-first, Earth parallel** (`THY-LAW-WORLD-FIRST-EARTH-PARALLEL-001`) | A single fictional frame | The EdereAirah model is built first. The Earth adapter comes second and is kept in a separate truth class (EARTH_ACTUAL / EARTH_PROPOSED). |

### 5.2 Life-tick state transition (Math Display Law)

**Name:** `MATH-LIFE-TICK-624` (PROPOSED id; not yet registered, and it does not redefine `MATH-SHARED-VISION-622`)
**Class: FORMAL_SYSTEM_LAW.** It defines how the system computes state. It is not a law of nature and not a behavioral model.

```
S_p(t₂) = fold( apply, S_p(t₁), ⟨ e ∈ L : e.subject = p ∧ t₁ < e.t ≤ t₂ ⟩ ordered by (e.t, e.seq) )

apply(S, e) = S ⊕ δ_e      if valid(e)
            = S            otherwise  (e is rejected and logged, never silently applied)

valid(e) ⇔ source_ref(e) ≠ ∅
          ∧ (is_real_person(p) ⇒ consent_active(p, e.t, e.kind))
          ∧ e.seq > seq_head(p)
          ∧ e.kind ∉ {RESET, DELETE, REWIND}
```

| Symbol | Meaning | Units | Domain |
|---|---|---|---|
| p | person (or any subject entity) | identifier | registered subjects |
| t₁, t₂ | as-of instants, t₁ < t₂ | UTC timestamp (Earth-read). Native calendar is **UNKNOWN** | t₁ ≥ t_BIRTH(p) |
| S_p(t) | state of p at t: a map from field to value, where a value may be UNKNOWN | unitless (structured record) | — |
| L | life-event log (append-only) | set of events | — |
| e.t, e.seq | event time; sequence number that breaks ties | timestamp; integer | seq strictly increasing per subject |
| δ_e | field changes carried by e | unitless | a field absent from δ_e is unchanged |
| ⊕ | overwrite-by-field merge. **UNKNOWN is never written by default.** A field leaves UNKNOWN only through an evidenced δ. | operator | — |

- **Scale:** one person, any span of time. A world tick is the same fold run over all subjects.
- **Threshold:** none. The fold is exact and has no tuning parameter.
- **Assumptions:** log order is total per subject; events are immutable; corrections are new events (`corrects_event_id`) whose δ restores or amends fields.
- **Failure conditions:** a missing `source_ref`; a real-person event with no active consent; seq out of order; any attempt at RESET, DELETE or REWIND. Each of these is **rejected and logged**. A failure never produces a partial state.
- **Plain English:** a person's state at any moment is exactly what you get by starting from their earlier state and applying every recorded, valid life event in order. Nothing else changes a life.
- **Child-readable:** your life story is a diary where pages only get added, never torn out. To know how you are today, you read the diary from the start.
- **Worked example** (illustrative world-canon subject, not a real person, EDEREAIRAH_PROPOSED):
  S(t₁) = {residence: UNKNOWN, role: UNKNOWN, age_orbits: derived}.
  Events in (t₁, t₂]: e₁ RESIDENCE_START {residence: place_A} with source; e₂ ROLE_START {role: role_X} with **no source**.
  Result: S(t₂) = {residence: place_A, role: UNKNOWN}. e₂ is rejected and logged, and role stays UNKNOWN.

**Derived quantity: age in orbits.** Class: FORMAL_SYSTEM_LAW (unit conversion against canon).
`a_p(t) = (t − t_BIRTH(p)) / T_orbit`, where T_orbit = **507 Earth-read days** (EDEREAIRAH_CANON). Units: days ÷ (days per orbit) = orbits.
- Domain: t ≥ t_BIRTH, and a BIRTH event must exist; otherwise a_p is UNKNOWN.
- Failure condition: no BIRTH event, or a DEATH event with t > t_DEATH, which freezes age at death.
- Plain English: age is counted in trips around the star.
- Child-readable: one trip around the sun at home is 507 of Earth's days.
- Worked example: 1,014 Earth-read days after birth → 1014 / 507 = **2.0 orbits**.
- Native-year and native-day conversions stay **UNKNOWN** until the calendar is recovered. (Time is the only quantity here, so the US/metric pairing law does not come into play.)

**Optional proposal generator (HEURISTIC, not built):** for **world-canon subjects only**, a generator may draft candidate events (EDEREAIRAH_PROPOSED). Each one needs review before it enters L as canon. Its probabilities, weights and cadence are all **UNKNOWN / not designed**. It never runs on a real person.
